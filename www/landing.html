Engine Anatomy

How Dracarys Executes Commands

A zero-friction, modular pipeline uniting modern Web frontend and native Python power.

1

Voice & Input Capture

SpeechRecognition engine or floating HUD capture user audio/text with automatic Hindi/English language identification.

2

Intent Resolver

Pattern matcher & NLP classifier determines whether to route to a local skill module or query the Gemini/OpenAI LLM.

3

Execution & Automation

Native Python execution runs OS actions, WhatsApp automation, document parsing, or system API calls in parallel threads.

4

Neural TTS & HUD Render

Synthesizes speech using Edge/Azure neural voices while Eel WebSocket sends live card updates and visualizer waveforms to the UI.

Python 3.10+ • Eel WebSocket IPC • Gemini 3.5 & OpenAI • Three.js 3D Canvas • SQLite Database

Install & Run Dracarys

Clone the open-source repository, install dependencies, and launch your desktop assistant. 

# 1. Clone repository
git clone https://github.com/MrAliHasan/Sophia-AI-Assistant.git
cd Sophia-AI-Assistant

# 2. Setup Virtual Environment
python -m venv venv
.\venv\Scripts\activate

# 3. Install required libraries
pip install -r requirements.txt

# 4. Launch the AI Virtual Assistant
python main.py
# Or double click 'run.bat' for one-click startup!
# TypeScript frontend bundle build (Optional if modifying src/ts)
npm install
npm run build

# Run unit and skill typechecks
npm run typecheck

# Run backend engine
python main.py
# .env Configuration File
ASSISTANT_NAME=Dracarys
AI_PROVIDER=gemini
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-3.5-flash-lite
SPEECH_LANG=en-IN
TTS_HINDI_VOICE=hi-IN-MadhurNeural
TTS_ENGLISH_VOICE=en-IN-NeerjaNeural
ASSISTANT_THEME=fire

Got Questions?

Frequently Asked Questions

Find answers to commonly asked questions about Dracarys AI assistant setup and usage.

Is Dracarys AI completely free to use?
Yes! Dracarys AI is open-source. It leverages Google Gemini's generous free tier and Azure Edge Neural TTS, allowing you to use all voice, document analysis, and automation capabilities without paying for API credits.
How does the bilingual English & Hindi recognition work?
Dracarys combines Google Speech Recognition (configured for en-IN and hi-IN) with a custom Python NLP language detector. It automatically detects Devanagari script or phonetic Hinglish, routes to the appropriate prompt context, and speaks back using Microsoft's neural voices (Madhur or Swara).
Can I add my own custom skills or automation routines?
Absolutely! All skills inherit from BaseSkill located in engine/skills/base_skill.py. You can create a new .py file in engine/skills/, implement the can_handle() and execute() methods, and Dracarys will automatically register and route commands to your new skill.
What formats are supported for document analysis?
The built-in Document Analyzer supports PDF (via PyPDF2/pdfplumber), Word documents (.docx/.doc), CSV, JSON, plain text (.txt), and Markdown (.md). You can click the paperclip icon or press Ctrl+U to analyze any file.
How do I switch between Gemini and OpenAI models?
You can open your .env file or use the in-app Settings panel (Ctrl+,) to set AI_PROVIDER=openai or AI_PROVIDER=gemini, along with your respective API keys.
